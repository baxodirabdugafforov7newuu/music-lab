# Music Lab

Basic React + TypeScript + Vite starter for a music streaming platform.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The app currently contains login and signup UI only. Forms use browser validation; submission shows a preview notice. Authentication, account storage, music playback, and streaming services are not connected yet. No credentials are sent or saved.
