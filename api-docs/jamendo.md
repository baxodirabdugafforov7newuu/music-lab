# Jamendo: optional independent music catalog

Not implemented. Consider it as another source of independent tracks and artist metadata if Audius does not cover the demo's needs. Jamendo IDs must stay separate from other providers' IDs.

Register an application and review the current plan, client ID requirements, track license, attribution, playback and download rules before implementation. Do not assume that an available audio URL allows redistribution or downloading. Suggested configuration: `JAMENDO_CLIENT_ID`; keep any application secret on a backend.

Official sources: [API v3](https://developer.jamendo.com/v3.0), [developer portal](https://developer.jamendo.com/). These are reference links; this provider was not live-tested or fully reviewed for this change.
